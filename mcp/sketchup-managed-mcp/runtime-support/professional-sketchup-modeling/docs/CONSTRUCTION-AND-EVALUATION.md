# 构造方法与评测基线

2026-09-11。本文件区分当前实现和后续引擎工作，不承诺未经对照实验的分数或提升比例。

已实现：可插拔经验读取、按主题阶段匹配、版本指纹、草稿隔离、公开底座与私有知识分包。模板支持“特征→候选构造→条件→参数→失败→修正→证据”。自主/引导是 Agent 的方法选择，不是新的 MCP 执行权限或阶段。

## 当前引擎限制与待实现验收

| 后续能力 | 实现前必须验证 |
|---|---|
| 可选任务路线 | 新建、局部修改、体块深化、复杂曲面各自声明前置成果；非重复任务不强制伪造实例；既有六阶段回归仍通过 |
| 上游受控修订 | 指定对象快照与回滚；依赖失效传播；只重建受影响对象；失败/中断恢复；保护其它根与未保存文档 |
| 任务相关复杂度预算 | 同时核验主要表面与负空间表达、重复浪费、目标视距误差；给明确冲突诊断；不能只有面数上限 |
| 通用构造工具 | 对应截面放样、共边分片、带厚度开口面板、宿主刚性放置、完整窗洞、转角端部、共享曲线驱动附属件；每项返回真实对象ID、适用域及失败示例 |
| SU 实体检查 | 沿程边界间隙、壳体朝向厚度、实例完整变换、墙顶梁底标高、定义与放置；标明对象类型/采样覆盖/容差，包围盒不冒充接触 |
| 独立视觉复核 | 参考与相机固定；定位差异；相同视角复查；记录实际复核人/工具；禁止自动盖章 |

以上尚未在本版实现，不应出现在 tools/list 中假称可用。优先选择常用一两类案例验证后再扩展。

## 同条件实验

选择规则住宅、古建屋面、渐变立面、局部修正任务。比较：仅工具、旧 SKILL/MCP、新版 SKILL/MCP。固定参考、预算、版本、视距与输出要求；每组重复运行，并单独记录桥接和视觉输入故障。使用 templates/evaluation.json 保存实验数据。

验收先判断轮廓/比例/负空间，再判断连接、样板完整、细部、可编辑性与交付。关键外观不通过不能被流程得分抵消。记录耗时、返工和人工介入；未知保持未知。没有实际实验数据时不发布模型排名、质量分数或提升比例。

## 运行故障与案例治理

错误码、实际现场、确认原因、排查假设、有效修复分别保存。截图失败不等于几何失败；权限差异仅是 PrintWindow 失败的一个排查方向，未经进程令牌等证据核实不得固化为原因。

案例可包含可编辑 SKP 的外部引用及校验和。当前 REF 本体仅承载文本与图片，SKP 不被自动加载或执行。保留用户拒绝的版本；成功保存过的文件不能直接成为合格案例。
