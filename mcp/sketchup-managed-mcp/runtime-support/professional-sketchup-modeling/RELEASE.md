# ADAI SketchUp 0.5.37

Build: `0.5.37-framing-shared-parameters-20260928`

基于 main@65f4053 增量修改。保留 guided 分步帮助、专家口令、局部更新、事务/回执和未知写入恢复。

- 整体与构件检查图按可见几何边界、实际画幅和相机方向取景；相机在成功与失败后恢复。
