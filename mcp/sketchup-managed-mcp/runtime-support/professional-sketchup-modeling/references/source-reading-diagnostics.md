# 来源误读诊断

**共用归属：guided与autonomous均使用本方法；执行顺序和审核时机由各自策略决定。**

来源：上游 checks.md §1–6、strict-review.md R1/R3/R4；已作适用条件修订。只处理当前影响主形或关键尺寸的疑点，不逐构件填表。

先确认所量的边界属于什么：实体外缘、洞口侧壁、遮挡、阴影还是反射。亮度边界与材料变化不能单独证明几何深度。图像分割在两组参数下结果不同，先回原图确认连续性；结果相同只说明稳定，不证明真实构件数量。

选择可靠的尺度基准：用户明确尺寸／图纸标注优先；可见实体轮廓和材料均一的长直边通常比玻璃、树木、深阴影旁的亮暗线更可靠。基准好坏还取决于它是否就是需要测的对象，屋檐外缘不能替代后方墙线。

跨照片或图纸组合前，确认同一建筑、时期、部位、测量端点和基准。相同风格或相同开间数只是身份线索。先排除扫描图横纵缩放不同、透视方向/深度不同；比值只消除共同等比例缩放，不自动消除透视。冲突先找原因，不取平均。

用户给定的尺寸无需再从照片证明。重要数量确有疑问且另一信号可用时，选择不同失误来源的交叉证据；同一边缘被同一检测器量两次不是两份独立证据。隐藏部分允许范围内的合理推断，不能冒充照片验证。

对于等距开间，可在适用投影条件下检查投影序列；它只能支持某种排列解释，不能凭残差反推唯一隐藏开间数或绝对米数。需要时查开发侧的公式审校，不临时照抄经验数字。

当前记录只保留“争议解读、关键依据、能推翻它的现象、受影响对象”。能用现有图或实际 SU 读回解决就自主解决；重大矛盾阻止依赖它的工作，不影响的合法工作继续。类型范围仅作调查提示，不能自动否定来源或设计授权。
