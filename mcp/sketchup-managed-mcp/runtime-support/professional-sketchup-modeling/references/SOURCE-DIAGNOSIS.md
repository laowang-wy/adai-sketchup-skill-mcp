# 定向源码诊断

发生真实接口或门禁错误时，先核对错误返回与对应 references。若仍缺少判定依据，允许读取当前绑定 MCP 的相关完整模块，包括 managed-project.js、managed_project.rb、质量检查、相机和投影函数；可用 rg 定位错误文本与调用链。只读源码不等于修改引擎，不能更改门槛、签名或项目状态来放行。

先从宿主明确绑定入口或随包 manifest 确认当前源码位置，不扫描全盘、不借另一版本解释当前行为。记录错误、文件、函数、发现的实际条件，以及准备修改的输入或阶段脚本。读到足够依据后回到建模，不无目标通读全库。

诊断构造需支持时使用受管最小样板，不能在活动文档裸写测试模型。读取源码不是完成建模，也不能替代真实图证。
