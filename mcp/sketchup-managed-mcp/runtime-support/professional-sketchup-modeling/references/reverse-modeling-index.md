# 共同专业方法：按问题路由

用于ADAI本地SU，共用经验维护一次，不是第二个Skill或验收器。先由短的[共同专业底座](shared-architectural-foundation.md)明确来源与成果要求；当前模式只读[引导操作](guided-operation.md)或[专家操作](expert-operation.md)。下表只有相关问题出现时才展开，已读同版本不反复发送。

| 当前问题 | 共享短卡 |
|---|---|
| 整体/局部、图片边界、数量、尺度或多源口径不确定 | source-reading-diagnostics.md |
| bbox相近但主形仍不像、轮廓/空腔/表示失真 | form-feature-review.md |
| 窗墙洞口、凹廊、楼板/支承、交通/接点 | assembly-review.md |
| 相机、投影、画幅、裁切或捕捉状态 | camera-capture-review.md |
| 材质/UV/实例继承、保存资源和交付后编辑 | materials-editability-review.md |
| 高返工风险或用户要求独立判断 | independent-review.md |

按需的是资料和方法，不是只在怀疑时才满足任务要求。全部专业卡两模式均可用；guided展开当前动作，expert自主选择方法与审核节奏。案例数值与建筑类型做法留独立经验包，不全装进共通底座。源码与开发测试不进入常驻上下文。
