# 曲面与包边共用实际边界

**适用：来源中包边紧接曲面边缘。** 用曲面自己的周边点生成包边，改变曲面边界时两者一起改变。建筑主体退进、屋盖悬挑或分缝仍用各自的边界，不把所有构件强行套到同一轮廓。

实际构造在 [shared-boundary-shell.rb](ruby/shared-boundary-shell.rb)。在受管 `build` 内调用；输入来自来源或明确推断，不是整栋建筑模板：

```ruby
# 从当前 Skill 的绝对路径加载上述 Ruby 文件。
g = context['geometry']
grid = [
  [[-6000,-2500,3000],[-6000,0,4100],[-6000,2200,3400]],
  [[0,-3600,3100],[0,0,5200],[0,3100,2900]],
  [[6500,-1800,3600],[6500,0,4300],[6500,1600,3300]]
]
# 周边次序：每行首点 → 最后一行余点 → 反向各行末点 → 首行中间点。
inner_xy = [[-5600,-2200],[0,-3200],[6100,-1500],[6100,0],
            [6100,1300],[0,2700],[-5600,1900],[-5600,0]]
parts = ADAISharedBoundaryShell.build(entities, g, grid, inner_xy, 180, 800)
```

`grid` 的每行覆盖当前截面的真实左右边界；端部收窄时，相应行的 XY 范围也收窄，不能只调整 Z 高度。示例坐标只说明输入组织，不代表建筑尺寸或推荐外形。

边界收成一个端点时，首末整行或整列可以重复同一个 XYZ 点。`shell_grid` 合并该端点并生成三角扇，`perimeter` 也只返回一次该点；内侧 XY 仍与合并后的实际周边逐点对应。内部网格继续保持有效面积。

程序把网格实际外边界下移屋壳厚度，作为包边外侧顶沿；再向下生成包边。内侧 XY 是显式输入，与外环逐点对应；它决定带宽，并非自动等距偏移。外边接触是准确的，内侧顶面不自动贴合整个屋壳底面。

需要独立使用时，`ADAISharedBoundaryShell.perimeter(grid,g)` 返回毫米周边点；可用于边带、栏杆路径或其它确实依附该边界的构件。母型的局部坐标、宿主位置和偏移从同一组点推导，放置变换只应用一次。方法超出当前条件时继续用独立轮廓、对应截面或自定义网格。
