# 相机、出图与几何分开检查

**共用归属：guided与autonomous均使用本方法；执行顺序和审核时机由各自策略决定。**

来源：上游 TOOLING.md §3/4/6/7 与 form-verification.md；Rhino API和窗口行为不迁入SU。

相机状态与图像处理状态分开记录。沿用当前受管相机/证据记录，补已有值即可：eye/target/up、透视或正交、FOV及方向、aspect、两点或匹配照片的可读状态；另记实际图片尺寸、viewport尺寸、裁切区域、等比缩放和原始文件hash。字段由程序获取，不让Agent重抄。SU camera.image_width是计算焦距的传感器宽度，不是截图像素宽度。

先用不同位置/深度的可辨认特征确认视图可比；只拟合外框不足以确定相机。几何修正时相机保持可比；投影确实错误时单独调整并重新取证。不用图片变形、独立裁切缩放或调镜头“修好”建筑。

既有原图是主证据。并排图保留全幅；叠图/像素差只在已确认的映射下用作诊断，不产生建筑合格结论。范围或截图比例变化只提示核对原因，不能自动归因镜头，更不能自动修改镜头。

检查截图的实际内容、当前项目与模型状态。命令成功、文件存在或像素非空都不能单独证明是当前模型；旧图不能用作新状态证据。维持现有采集前后保护与相机恢复，不用离线图处理器绕过受管捕捉。

派生图在封存前生成并纳入原证据文件清单，优先复用现有 make_visual_review_sheet.py。封存后辅助缓存不能修改原record；当前引擎不支持带父hash的派生证据时，缓存只作辅助，不能冒充已封存视图。
