# 引导操作：把共同经验转成当前可执行动作

新建 guided 保留完整主形、代表构件、复制、变体、表皮、收尾的引导路线；CAD与修改按各自实际计划执行。`omit_phases` 和 `repetition=none` 不删除新 guided 的步骤；没有适用的新增构造时核对现有成果，明确观察后推进，不制造无用组件或实例。同阶段相关构造可合批，已有签名项目仍按保存路线接续。

`begin → 当前阶段step → 实际看图 → review` 是默认节奏；受管阶段重跑仍替换该阶段，不累加重复垃圾。先推导整体主尺度、标高、负空间与关键接口，再分阶段提交；先完成能解释来源的样板和宿主关系，再复制。不以计数、登记动作或方法标签证明建筑正确。

共同主形经验与专家相同；弱模型获得当前步骤、真实参数来源、一个适用例子和明确修法；需要自定义 Ruby 时再读取 `references/ruby-snippets.md` 中对应 helper，不全库加载。合法单系统不强造第二系统；明确需要A+B时缺B必须指出。源图不足时记录重要假设，不编造权威数值。

同一原因引起、且属于本阶段的相关修正可合并；不为“一轮一个问题”重复抄参数。检查视图沿已有路线，先看总览与对照，必要细节再读原图。重复失败时重新判断边界、比例和表示，不写够字数才允许继续。

简写视觉审核由程序组装机械检查：只需真实观察、结论及实际看过的图片引用。发现已审构件的局部错误，先处理未决操作，再用 `step(operation_intent=update, targets=[...])` 定向修正，复核后接续原阶段并保留无关成果；需要整阶段重建时才用 `revise_from`，按返回检查点和影响范围处理。

提交后失败不一定是构造失败，按工具返回区分已提交、未提交和未知。未知用原回执恢复；已有成果缺证据只补证。`finish`输出真实文件后才交付，未实测编辑/重開明确说明。
