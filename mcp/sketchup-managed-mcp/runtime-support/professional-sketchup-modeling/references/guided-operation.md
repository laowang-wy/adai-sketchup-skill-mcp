# 引导操作：把共同经验转成当前可执行动作

默认模式保留已保存的阶段路线：新建通常为体量、代表构件、复制、例外、一次性细节、收尾；CAD与修改按实际返回的路线处理。按当前任务选择相关经验，不为没有的系统编造步骤。

`begin → 当前阶段step → 实际看图 → review`。受管阶段重跑仍替换该阶段，不累加重复垃圾。先推导整体主尺度、标高、负空间与关键接口，再分阶段提交；先完成能解释来源的样板和宿主关系，再复制。不以计数或方法标签证明建筑正确。

共同主形经验与专家相同；弱模型获得当前步骤、真实参数来源、一个适用例子和明确修法。合法单系统不强造第二系统；明确需要A+B时缺B必须指出。源图不足时记录重要假设，不编造权威数值。

同一原因引起、且属于本阶段的相关修正可合并；不为“一轮一个问题”重复抄参数。检查视图沿已有路线，先看总览与对照，必要细节再读原图。重复失败时重新判断边界、比例和表示，不写够字数才允许继续。

简写视觉审核由程序组装机械检查：只需真实观察、结论及实际看过的图片引用，不重填回执或缺附件原因。已审原型错误先处理未决操作，再使用 `revise_from` 回退相应阶段及实际下游；不得另建项目规避。

提交后失败不一定是构造失败，按工具返回区分已提交、未提交和未知。未知用原回执恢复；已有成果缺证据只补证。`finish`输出真实文件后才交付，未实测编辑/重開明确说明。
