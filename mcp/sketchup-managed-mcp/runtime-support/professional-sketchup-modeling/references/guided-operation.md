# 引导策略：共同专业经验的分步应用

此片段供开发合并，不是另一份Skill。默认guided，沿用已发布的结构化阶段和当前任务范围；正确的引导能力不因增加expert而被删掉。

始终应用[共同专业底座](shared-architectural-foundation.md)。每个当前步骤给出足够直接执行的目标、已知参数/来源、适用配方或已有工具、预期结果和针对性纠错；遇到来源误读时给可区分的观察方法，不只说不合格。

可复用实际适用的经验包生成器，也可合法受管自定义Ruby；没有配方不等于不能建模。先解释主形/空间与关键尺度，再细化受影响系统。原型与接点代表检查帮助减少重复错误；任务确无重复系统不强造实例、第二细部或无依据装饰。

一次只提交当前允许范围；同阶段、同一原因与清楚作用域的修正可合并。必要取证和当前反馈继续有效，已读同版本不重复。程序负责机械登记/ID/hash/状态，模型不抄完整表格。Node与Python的旧规则冲突须修正，不作为弱模型必须服从的要求。

结果未知先查原回执；证据采集失败只重取证，不重写几何。已接受原型需返修时，在允许状态用实际实现的revise_from，不另建项目躲过保护。权限和用户工作不因guided改变。

实际图像与读回判断主形、装配和可编辑性，不因阶段记录齐全就完成。简短报告当前缺陷、依据和下一步；无须记录长篇内部推理。
