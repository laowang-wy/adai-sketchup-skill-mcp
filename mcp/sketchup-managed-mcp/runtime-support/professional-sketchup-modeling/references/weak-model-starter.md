# SU-START/1
保留用户原任务与来源；本卡只给执行要点。

STATE：沿用实际返回的项目、阶段、请求、证据和下一步，不另填表。
PRE：维护文档不启动 SU；先核对真实进程、绑定实例、文档和未保存状态；目标不唯一就重选，不猜 EXE。
ACT：按当前阶段执行，算法可自选；先主形、空间和连接，再构件与细节；step→看真实证据→review。工具成功不等于造型通过。
FAIL：evidence_pending 只 retry_evidence；超时先查状态，未知结果不重放；连续两次同错停止重复并报告事实、未知和下一步。
PROVE：没打开的图不算看过；数值标 live_readback/declared/image/unknown；修关键偏差后同视角复查，交付须有回执、文件和证据。
BUDGET：已选实例反复消失时停止写入并核对一次；先看 review sheet，必要视图缺失或不清再开原图；只取所需 JSON 字段，完整证据留在文件。
