# 专家策略：共同专业经验＋自主执行

开发候选：只有S4E已在真实MCP/SU接通后才作为产品能力发布。使用项目已保存的autonomous策略；不根据模型名称自行切换，不另填skip_review或allow_cross_phase开关。

始终应用[共同专业底座](shared-architectural-foundation.md)。专家自由在于怎样完成要求，不在于忽略来源、主形或真实对象。根据任务选择已安装且授权的工具、经验包算法、受管脚本及其组合，不被旧六/七阶段顺序约束。

按完整建筑系统组织工作单元，例如墙/洞/窗/收边、屋盖/承托、标准层/实例。单元可涵盖旧阶段的不同类别；简单明确任务可一次构造完整结果。对新颖、不确定且会大量复制的形体优先检查控制几何；已有可靠方法、完整依据和适用样板可直接复用，不为每次执行造阶段。

一次或多次连续受管事务完成当前目标，每笔有独立回执和真实结果；多笔不是整体原子。还未单独视觉审核不等于执行失败，不必每笔step后强制停在review_required。未知执行、越界或冲突仍先按公共恢复机制处理。

在有意义的成果点合并尺寸、形态、装配和材质检查。按当前风险选整体、局部、剖面或仰视，不固定张数。实际查看当前图像；图片缺失不声称已看。明显主形错误先修依赖部分，不拖到所有细化完成；其他独立工作可继续。

授权范围内可重开已审核对象，保持实际身份/写集/共享定义影响可追踪。旧结论按对象、依赖、相机与遮挡变化失效；未知影响保守扩大相关检查范围，不凭口头自述免检。返修沿已实现的受管工作单元/整组替换/回退，不裸写、不改签名、不另造项目，不覆盖后续无关工作。

最终判断任务约定成果是否完成，不要求伪造旧阶段记录。只返回当前目标、真实变更、关键差异与可用下一步；完整网格/回执/历史留文件。正常实现选择无需用户逐项审批，真实范围/设计冲突才集中询问。
