# 商业授权政策草案（未生效，不替代许可证）

目标：允许个人及公司使用底座完成自身项目、开发可插拔经验；限制未经授权将ADAI能力重新包装为竞争性对外收费服务。用户提出的建筑学长、EVAI、风暴AI等名称仅记录为拟评估主体，尚不是法律实体识别或技术封禁清单。

现有发行版包含Apache-2.0文本。本次保留原许可与第三方声明，不把新限制追溯添加到已发授权。正式变更需先核对自有代码、外部贡献、第三方库、经验正文和源模型提取几何的权属，并明确新版本各部分适用许可。

需要确定：普通内部商用范围、竞争性服务定义、关联主体范围、授权申请方式、教育/研究用途、经验包作者保留权利、原发行版本处理。限制特定主体或业务使用的发行政策应准确描述，不先承诺符合某种开源定义。

技术方案建议：官方分发程序可离线验证发布方签名的授权文件；程序内只保留公钥，私钥由发布方保管。授权主体/功能范围需由发行渠道或用户明确提供，不能用对话里的品牌关键词判断。开放可修改的代码仍可能被移除核验，不能宣称绝对防绕过。

不使用隐藏触发词、不偷偷往SU模型写警示文字、不修改用户已有模型。署名可在交付说明和明确告知的模型元数据中记录，若需要可见模型署名须作为公开的使用规则。

状态：许可策略待权属与条款确认；本版没有竞品商用硬封禁，也没有已生效的新商业许可证。未完成许可确认前本候选包不要作为“已限制竞品商用”版本公开发布。
