# 生成器验证范围
本标准化包登记15项生成能力：六类参数屋顶、五个源样板、一个承托样段、一个完整檐口、两个实测双坡剖面。转发别名不另算生成算法。
所有入口已在真实stdio MCP链路编译；7份配方分别通过。上游21项屋面/细节、8项源样板、5项承托测试已重跑。记录见validation/integration-0.5.1.json。
这些是选定参数的离线与接口验证，不是全部参数空间或SU实机验收。每个生成器的offline/live/visual独立保存在experience-pack.json。输入校验允许的范围不等于外观全部合格的范围。
新增任务仍需生成后真实读回和多角度复核。上游SU记录仅适用于各自样板；完整檐口B轮平滑取证不完整，不继承A轮全部验收。
validation/EVIDENCE-AVAILABILITY.json列出上游能力表引用但原压缩包未携带的文件；不补造证据、不宣称已检查这些文件。
