共12张经验卡；`python experience_tool.py list` 查看清单，`show ID`只加载任务匹配卡，`check`检查引用和配方。

复制配方到新位置后调整明确参数，validate、compile，按 PACKAGE-GUIDE.md 通过受管MCP执行；实际看图与读回通过后才用于后续装配。弱模型负责选择和输入，不需自行重写曲线、切瓦或榫口算法。

源模板、诊断木构、通用屋面与历史精确复原是不同范围。本轮不扩展整栋岳阳楼，不承诺所有类型屋顶和所有斗拱制式自动完成。
