# 长空阁斗拱：本次实际观察

读取用户指定长空阁 SKP，文件 SHA256 前后相同。结构审计为 1051 个组件定义、3 个组定义。只抽取与本次相关的组件，没有把全部 165 万展开面复制成工具。

实际打开提取的透视图后，确认 C0730 为低矮十字交叉组件，C0732 为多层出跳组件。C0728 是柱状构件，不能因靠近屋顶而归入斗拱。C0494、C0522 仍仅作候选，不作为已确认斗拱。

C0730 使用 C0027 两次和 C0026 一次，共 340 源展开面。C0732 使用 8 个直接子实例，其中 C0027 重复 4 次；加上 C0026、C0029、C0028、C0033，共 1092 源展开面。其底座与不同标高的拱臂组成整体，不能仅通过沿 Z 轴重复同一“斗”来恢复。

“廊架古建”的 C0042 正身件和 C0044 转角件有不同构件网络；“长空阁”的这两件不直接映射到那套正身/转角命名。当前使用中性的 cross/layered ID，避免将未经判断的模型细节命名为具体古制。

学习成果已经进入 source_template_tool.py：源网络、完整变换、定义复用、统一比例和严格参数合同。当前不包含结构计算、历史形制鉴定、任意出跳层数变化与自动承托求解。
