# 王府源模型屋顶学习记录 — 2026-09-12

本次读取王府2四合院 SKP 的9个定义：G0916、G0918、G0915、G1031、G1032、G0120、G0121、G0443、G0457。源路径及两次读取前后 SHA256 在 wangfu/provenance.json 和 wangfu-details/provenance.json；均一致。此前批量结构读取不等于全部模型外观学习。

## 实际观察

G0916/G0918 为同剖面的双坡屋壳，各52个原始面；G1031/G1032 是另一组双坡屋壳。实际外环坐标显示每个完整剖面25站，每半坡12段；各站上下表面相差0.15m竖向厚度。G0916半坡跨度6.81m、升高3.680741879m；G1031半坡跨度约5.0099m、升高2.35m。尺寸是模型内几何，不是实物测绘。

G0916跨坡轴Y、挤出轴X；G1031跨坡轴X、挤出轴Y。未先检查轴会错误提取常数高度。工具统一输出长脊X、跨坡Y，并保存原始轴。

实际看过 G0916/G1031 的透视派生图。它们以沿脊平行的分段面组成坡度渐变，不存在四角集中一个尖点的布局。两组相配的壳体是分开的源定义，装配中有不同标高；不得据此称整个屋顶只有一层。

复杂 G0810 内的 G0390 多次引用 G0120/G0121；G0120 派生图显示连续跨脊的曲线窄带，G0443 显示有重复起伏的面板。由结构和形状可推断这是瓦面构件复用的线索，尚未分析每块瓦的搭接与材质，不能说已提炼完整铺瓦器。

G0810后代的定义局部坐标尺度巨大，而外层实例缩放后装配为十余米建筑。当前细节图只标局部单位，不能直接作为瓦件实物尺寸。必须合成完整父变换后才建立尺寸预设。

## 落地成果与限制

prepare_measured_loft.py 以源站点归一化数据放样，输入长、跨、升高、厚度，输出可编辑封闭屋壳。它没有实现四坡、翼角、盔顶或歇山的分坡拓扑。剖面数据绑定源哈希和文件哈希，不能静默改变。

G0916在SU2019受管执行完成：98个面、196条边（端部按站分段，故不等于源52面）；实际 manifold、面循环双向共边、顶点与编译网格最大误差<0.01mm的断言全部通过。已看SU透视和侧视，直脊/曲坡/封边与源派生图对应。差异是网格分区，不是源网格逐面复制。G1031只做离线尺寸/闭合测试，尚未单独SU生成。

统一契约的helmet候选壳体在SU也执行通过。已看透视/檐下，无前述髋线锯齿；仍是单中心四坡候选，不是岳阳楼盔顶风格验收。保留review_required，未声称生产通过。

当前运行SU进程为19.0.685，实际加载NVIDIA OpenGL，并非配置中的隔离软件渲染；本次window_print实际产出了可查看多视图，不声称隔离渲染核验通过。未重启或破坏活动文档。
