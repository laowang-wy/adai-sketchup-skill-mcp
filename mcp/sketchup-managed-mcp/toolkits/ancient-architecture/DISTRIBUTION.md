# 分发说明
古建经验来源版本 0.4；经验包版本 0.4.2（experience-pack.json）；可执行工具包版本 0.4.6（toolkit.json）；集成的 MCP 版本与构建见主包 manifest.json / BUILD.json。经验开发者：老王；整合发布：ADAI。
原始源包哈希清单保留在完整开发归档中，仅用于追溯原包；当前规范化文件的完整性由package-manifest.json校验。
历史路径已替换为不可解析审计标签，源SKP哈希保留，网络文件哈希相应更新。开发归档清单不是当前文件哈希清单。模型原始SKP与整份文档检查点不分发。
源码与来源几何许可不同；保留各自来源条件，不自动授予第三方素材的额外权利。Python3.10+和numpy由宿主事先准备；运行时不联网安装。
PACKAGE-GUIDE.md仅为工具使用指南，不注册独立Skill。日常生成无需SDK或素材盘；只读提取器已移至开发归档。
当前项目按来源特征选择返回的方法；需要屋壳生成器时沿 `preset → compile → ruby_file → sketchup_project_step` 执行。普通受管构造不要求测试前缀。当前主包的验证范围见主包 RELEASE.md；历史 SU 记录仅适用于原指定参数与版本。
