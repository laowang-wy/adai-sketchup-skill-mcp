## 改动

- 复用现有相机捕捉模块，以可见实体包围边界的八角点、当前视角、实际画幅及真实 FOV 方向计算取景。用于整体、语义对象和代表构件视图；不增加出图次数。
- 普通对图页复用已生成的整体透视，保留原参考图。显式对齐或局部框选仍使用指定相机；不推断照片机位，不生成相似度结论。
- 交付保留可用的当前视角；对象偏出画面、被裁切或过小时，仅在保存副本时临时采用整体视角，随后恢复现场相机。检查点保存语义、事务、回执及未知结果恢复保持。
- 修正合法派生图在 Windows 长短路径写法不同情况下被误判为越界的问题，按真实目录检查；并未放开目录边界。
- 替换代表构件示例：一套尺寸推导真实墙洞、窗框截面、墙厚退深和实例位置；母型放在宿主上检查后复制。主 Skill 只调整现有重复构件行的指导与链接，没有新增必读文档、审核阶段或证明表。

这不是自动约束求解器：共享参数供构造脚本复用，修改已有几何仍使用现有受管更新入口。没有写入建筑名称、特定层数、风格或项目尺寸规则。
