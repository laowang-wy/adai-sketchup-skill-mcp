# ADAI SketchUp 0.5.39 修订构建

Build: `0.5.39-construction-inspection-20261003-r1`

基于 main@1c55ed9，本次发布当前构造辅助、图像交付和局部修改候选，保留品牌口令、许可、文档/对象保护、事务及原操作恢复。

- 两模式共用可选 Ruby 构造方法：轮廓挤出、带孔轮廓、变化截面、曲面薄壳、围合带及控制曲线采样。返回真实输入与适用边界，不用某一种算法限制全部建筑。
- guided 图片/文字新建保持完整主形、代表构件、复制、变体、表皮细节、收尾六阶段，分别执行与审核；`omit_phases` 和 `repetition=none` 不缩短新 guided 计划。局部修改保留已建成果与原进度；历史项目沿用保存策略。
- 专家保持工作单元、连续写入和合并审核；起步主形与适用代表构件要求不变，没有加入 guided 六阶段。
- 取证回复直接附当前封存对照图。guided 图片任务前两阶段在同张图中加入已经捕获的正视与俯视，不增加捕获；专家默认展示不继承此扩展。两模式可以选择视角与局部对照。
- guided 已审结果可只补观察图，不重建、不重新开启审核；局部对象发现返回准确地址及可选修改方法。已提交脚本保留独立副本，错误回复保留失败位置和原操作身份。
- 照片透视图可暂时隐藏显示边线，保留原显示选项；取证临时显示本项目、隐藏其他顶层对象，结束或失败后恢复可见性与视口。

验证范围：当前源码回归 301 项通过，136 份运行源码语法检查通过。测试使用真实业务模块与公开 stdio MCP；协议测试的 SU 边界为显式替身。运行 ZIP 另行解压核对 Skill 镜像、RBZ、哈希与公开入口。开发测试与用户模型不随包分发。

同源功能候选曾在 Windows SU2019 定向验证构造、局部修改、回滚、可见性恢复与对照图交付。上述工程检查不等于最终安装包的整栋来源还原验收；最终包安装后完整建模/重开、跨机器及实际 token/费用收益本轮为 `not_run`。

古建工具包 0.4.7、经验集合 0.4.3、REF 1.4.0 版本保持独立。当前运行测试使用固定副本；发布不切换活动安装。
