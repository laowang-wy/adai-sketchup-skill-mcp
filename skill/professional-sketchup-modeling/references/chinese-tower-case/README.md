# Chinese tower case image inventory

This directory contains selected read-only evidence for [the Chinese tower image-modeling protocol](../chinese-tower-image-modeling.md). Definition keys, counts, transforms, and limitations are recorded in [the case evidence JSON](../chinese-tower-case-evidence.json). A `Cxxxx` filename is an enumeration key from that audit, not a persistent cross-file entity ID.

- [embedded-preview.png](embedded-preview.png): the SKP embedded preview, useful only for broad composition clues.
- [C0493.png](C0493.png), [C0786.png](C0786.png), [C0797.png](C0797.png), [C0853.png](C0853.png), [C0988.png](C0988.png), [C0993.png](C0993.png), [C1021.png](C1021.png), and [C1043.png](C1043.png): diagrams generated from actual face outer loops for the corresponding selected definitions.

These diagrams omit complete materials, textures, face holes, and true rendering occlusion. They cannot prove semantic identity, surface contact, historic construction authenticity, or final model quality. Load only the images relevant to the current question.
