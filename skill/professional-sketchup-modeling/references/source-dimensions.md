# 已确认尺寸：一次绑定，程序预检与实际读回

这是一条窄范围能力，不是全建筑约束图。只在已有用户尺寸或可信资料、对象口径明确时，在begin的`task_profile.dimension_targets`中绑定一次。不能为了满足字段制造目标；没有尺寸的自由设计不必填写。

```json
{
  "dimension_targets":[
    {"object":"main_wall","axis":"z","expected_mm":3200,"tolerance_mm":5,"source":"用户任务书明确的墙体高度"}
  ]
}
```

`object`可对应受管操作id、几何适配器semantic_id或明确唯一的组/组件名。`axis=x/y/z`是该对象内部坐标轴；实际长度包含完整父级/实例缩放，旋转不会把世界轴对齐bbox误当物体宽深。测的是该对象局部几何范围，不是屋脊标高、围护面积或柱网位置；不能把不同口径强行映射成相同尺寸。

同名多个出现、缺对象、剪切或奇异变换等无法可靠测量的情况返回unverified。一般平移、旋转、非均匀正交缩放可测。具体对象绑定/来源仍是模型判断，程序不自动认证引用来源的真实性。

专家typed box/wall在创建面之前做参数预检；最终仍重新测量实际几何，不能用输入回显自证。自定义Ruby/复杂生成器使用实际读回，不假称对任意代码都做了生成前尺寸证明。

取证自动生成并封存`source_dimensions`；模型不另填测量报告。明确不符阻止相应审核；尚未构造的目标保持未验证，最终finish要求已绑定目标都由当前实际测量通过。没有绑定的尺度依然需要按任务实际核对，不把空目标数组称为全项目尺寸合格。

正常修改复用已有目标。需要更改用户已确认的目标属于任务变更，本构建没有开放随意覆盖已存目标的入口；不要手改签名状态。旧项目与复杂来源的目标迁移应由维护者按真实授权处理。
