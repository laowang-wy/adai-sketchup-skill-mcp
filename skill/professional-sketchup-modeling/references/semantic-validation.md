# 语义重建与验收规则
Read after `cad-to-su-fidelity.md` and `trace-manifest-schema.md` for any source-bound interior/layout task. It determines object role, facing, host/contact, and semantic readback; it does not replace the trace schema.


## 语义重建（有源任务必须）

**先重建语义，再加细节。** 综合使用块内部结构、房间归属、邻接关系、尺寸、标注、
重复符号、用户确认；**绝不只从 bounding box 或块名判断**。

**用户确认的语义有约束力。** 让确认覆盖不确定的自动标签、通用 `source_kind` 值、
视觉上合理的惯例。

**不要把一个通用来源类别的所有实例都映射到一个模板。** 区分：
休闲椅、餐椅、书房椅、大凳、小凳、脚凳、梳妆凳；
同样地，按房间和用途解析 X 标记柜，而不只是按符号。

**记录每个对象的功能角色、本地正面轴向、朝向目标、宿主/接触关系、置信度。**
示例：`front_axis`、`facing_target: sofa`、`screen_facing_axis`、`host_wall_side`。

### 座椅
验证座、靠背、扶手、腿、缝线及其他子部件遵循来源旋转，
面向预期的沙发、桌、书桌或流线区。

### 墙挂物件
建模前确定所在房间和宿主墙侧。
电视必须朝床或沙发露出屏幕，把安装支架留在墙侧，保持可见而不是
与墙共面或埋进墙里。

### 保存的旋转属性
把存储的旋转属性当作**证据**。确认实际子几何被变换了；
元数据写着 `90` 或 `270` 度不能证明椅子本身被旋转了。

## 变换与 Footprint 安全

**本地组件尺寸** 与 **旋转后的世界轴 bounding box** 分开。
绝不把旋转后的世界 AABB 反馈回本地几何再旋转一次；这会静默放大 footprint。

**从权威来源几何和来源旋转恢复本地尺寸**，或在组件的本地坐标系中测量。
恰好应用一次父变换。

**精细化之前捕获预期的来源 XY 边界。** 替换内部几何后，
与该基线比较 min/max XY、中心、尺寸、旋转、语义锚点再保存。

**在已验证 footprint 内部添加真实感。** 用合法的到边部件如：
周边护栏、框架、腿、垫子，当精确范围必须保持稳定时；
不要添加无法解释的 footprint 平板纯粹为了强制 bounding box 匹配。

**保留追溯的父组**及其来源属性。重建内部部件时，
补丁拥有错误语义的最小命名组。

## 语义-视觉验证

**用上下文视图和特写视图验证每个修正对象。** 显示对象与建立其含义的
床、沙发、桌、书桌、墙或洞口在一起。

**朝向不确定时，从两侧检查宿主墙物件。** 确认用户侧显示屏幕/正面，
墙侧显示安装支架/背面。

**拒绝墙、玻璃、家具或相机裁剪隐藏目标的截图。** 重新定位相机并检查实际图像；
成功导出图像本身不是视觉证据。

**结合机器可读检查**：部件名称、朝向轴向、变换、来源句柄、前/后边界。

**从磁盘重新打开保存的 `.skp` 并重复语义审计。** 确认座椅类型、
餐椅旋转、电视朝向方向、窗墙填充、轨道、来源追踪在回读后存活。

**更新永久生成器或精细化 pass**。修正活动模型后，
不要留下会重新创建被否决模板或朝向的再生路径。

## 布局审计清单（最终保存前检查）

- [ ] 入口门开启不撞鞋柜、餐椅、植物、地毯
- [ ] 卧室和卫生间门扇不与桌、椅、灯、柜碰撞
- [ ] 餐椅有拉出净空；细节件跟随椅子旋转
- [ ] 餐椅背离桌、座面朝桌；四把椅是独立椅组件而不是拉伸的长凳盒子
- [ ] 休闲、书房、餐厅、卧室座椅用角色适当的构造，而不是一个共享通用椅模板
- [ ] 墙挂电视朝沙发或床，在所在房间侧露出可信的 16:9 屏幕，墙挂几何在反面
- [ ] 茶几和地毯不重叠餐厅座椅区
- [ ] 马桶、浴室柜、淋浴、面盆尺寸适合卫生间且不重叠
- [ ] 窗台植物、窗帘、框保持在室内不穿墙/玻璃
- [ ] 灯具对无顶模型在结构上讲得通
- [ ] 细节组不浮空、不重复、不脱离它描述的对象

## CAD-to-SU 完成闸门（有源任务全部必须通过）

- [ ] 每个相关的非空 CAD 图层被映射或显式排除（附权威和理由）
- [ ] 每个选来建模的来源对象有目标 SU 组和来源追踪
- [ ] 按语义类别的来源和目标对象数量匹配
- [ ] 墙类包含保留/新建/拆改/完成面语义（任务需要的）；无墙类被静默过滤
- [ ] 家具中心、footprint、旋转、语义锚点在声明公差内匹配。
      床额外验证床头贴墙；柜验证正面/接触面
- [ ] 实际子几何（不只是存储的旋转元数据）遵循来源朝向和功能朝向目标
- [ ] 上下文依赖符号和通用家具类解析到正确的房间特定语义类型；
      用户确认的电视、柜、凳、椅不留作模糊面板或共享模板
- [ ] 墙挂物件验证宿主墙、所在房间侧、前/背方向、可见性、墙接触
- [ ] 目标新增列表不含未批准对象
- [ ] 前/后叠加或配对俯视图确认布局等价
- [ ] 运行 `scripts/validate_trace.py <trace-manifest.json>` 并修正每个错误
- [ ] 空间碰撞、流线、层级、材质、保存/回读检查也通过
- [ ] 活动模型修正及其永久生成/精细化路径在再生后产生相同的被接受语义
